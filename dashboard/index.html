ANALYSIS PIPELINE

What happens to a URL?

01
Normalize & parse

URL components are normalized locally; invalid schemes are rejected.

02
Extract 14 features

Feature names, ordering, and entropy calculation match the Python training schema.

03
Run the trained model

The deployed model returns benign and phishing probabilities, with its version attached.

04
Explain observed signals

URL heuristics are listed separately from the model probability so evidence is inspectable.

ⓘ

Scope matters. The current agent performs local URL-feature inference only. It does not browse the destination, validate its TLS certificate, or contact external threat-intelligence providers.
