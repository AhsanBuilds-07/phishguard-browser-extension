How it works

Five checks. One verdict. Zero round-trips.

Every navigation runs through the same pipeline, in order, inside Chrome's V8 engine. Nothing waits on a network call.

> url     paypal-verify.xyz/signin
> signals …
> model   …
> brand   …
> glyphs  …
> dom     …
  1. 01

    Lexical extraction

    Length, dots, hyphens, subdomain depth, raw IPs, “@” masking, risky TLDs, lure keywords and Shannon entropy — 14 features in one pass.

    extractFeatures(url) → Float32[14]
  2. 02

    Random Forest inference

    A scikit-learn ensemble transpiled to plain JavaScript with m2cgen. No WASM, no remote weights, no dependencies.

    predictProba(x) → [0.12, 0.88]
  3. 03

    Brand impersonation

    Checks the registered domain against 16 protected brands, catching subdomain abuse and Levenshtein-close typosquats.

  4. 04

    Homoglyph & punycode

    Flags Cyrillic and Greek lookalike letters and xn-- domains that render identically to the real thing.

  5. 05

    Credential guard

    Inspects where password forms actually post. If the destination is a bare IP or plain HTTP, submission is locked before you hit enter.
